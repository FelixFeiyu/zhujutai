# 追剧台

**一个窗口，集中管理你在不同平台追的剧。**

追剧台是一款 Mac 视频聚合应用。芒果 TV、哔哩哔哩、腾讯视频、优酷、爱奇艺、央视直播与 YouTube，都能从同一个侧栏进入。少开几个浏览器标签，少在几个应用之间来回切换，把找片、收藏和继续观看放在一起。

[下载最新版本](https://github.com/FelixFeiyu/zhujutai/releases/latest) · [问题反馈](https://github.com/FelixFeiyu/zhujutai/issues)

## 为什么用追剧台

- **找片更集中**：常用视频网站放进同一个窗口，选个平台就能搜索、浏览和观看。
- **想看的内容放在一起**：收藏电影、视频和正在追的节目，回到收藏页找到它们。
- **接着看更省心**：在能识别节目、集数和播放器进度的场景下，记录观看位置并尝试续播。当前仍有平台限制，见下方已知问题。
- **留更多空间给画面**：折叠侧栏，配合影院模式和深浅外观，按自己的习惯调整观看环境。
- **切平台时保留现场**：各平台可以独立设置是否保留后台网页，减少重新打开页面的操作。后台保留与侧栏折叠是两项独立设置。
- **选择习惯的播放方式**：可以在窗口内观看，也可以交给系统默认浏览器或已安装的官方客户端；客户端直达能力因平台而异。

## 怎么用

1. 打开追剧台，从侧栏选一个平台。
2. 在官方网页搜索想看的内容，按需要登录自己的平台账号。
3. 把感兴趣的内容加入收藏，之后从收藏页继续观看或追更。
4. 观看时可收起侧栏、切换影院模式和深浅外观；需要换播放方式时，使用“客户端打开”或“浏览器打开”。

追剧台是个人制作的统一入口，与各平台没有官方关联。它不提供影视资源、账号或会员，不解锁付费内容。VIP、广告、清晰度、地区限制和 DRM 仍由各平台决定。

## 系统要求

- Apple Silicon Mac（arm64），macOS 14.0 或更高版本。
- 当前安装包不含 Intel x86_64 程序，不承诺 Intel Mac 兼容。
- 当前版本：2.1.6（24）。应用文件内容合计 2,349,529 字节，ZIP 1,895,754 字节；磁盘占用会随文件系统变化。

## 下载与安装

1. 在 [Releases 页面](https://github.com/FelixFeiyu/zhujutai/releases/tag/v2.1.6-24)下载 `zhujutai-2.1.6-24.zip`，并可用同一版本的 `SHA256SUMS.txt` 校验文件。
2. 解压后把 `追剧台.app` 拖入“应用程序”文件夹。
3. 从“应用程序”打开追剧台，选择平台并在平台官方网页登录。

当前应用采用 ad hoc 签名，没有 Developer ID 身份，未提供 Apple 公证证明；严格签名校验通过不等于 Apple 公证或安全认证。其他 Mac 可能受到系统安全机制阻止。遇到阻止时请遵循系统提示及 [Apple 官方安全说明](https://support.apple.com/zh-cn/102445)，不要关闭系统保护；如无法正常安装，请反馈并等待后续签名发行版。

## 功能与使用

- **网页平台聚合**：在侧栏选择平台，通过官方网页搜索和播放内容。
- **收藏与追更**：把感兴趣的内容加入收藏，回到收藏页继续观看；节目和集数可识别时保存进度并尝试续播。
- **侧栏折叠**：收起侧栏获得更多观看空间。
- **各站保留后台**：按平台控制离开后是否保留网页。此设置与折叠侧栏是独立控制；保留后台可能增加资源占用。
- **影院模式与深浅外观**：调整窗口观看环境。
- **客户端与浏览器打开**：把当前内容交给已安装的平台客户端或系统默认浏览器；直达能力因平台和内容而异。

播放权限、VIP、付费、广告、地区限制和 DRM 由各平台决定。追剧台不提供账号或会员权益，也不解锁付费内容。网站与客户端账号状态可能不同；网络可达性依赖本机网络环境。

## 已知问题与验证范围

- **芒果 TV**：从收藏追更打开后，前后拖动进度可能回弹到旧位置。用户已报告，根因未定，尚未修复。
- **哔哩哔哩**：官方客户端指定视频直达未解决。
- **腾讯视频**：部分环境续播受到 HDCP 限制。
- **优酷**：重开广告后的完整续播流程尚未验收。
- **爱奇艺**：首次点击客户端打开并直达同一视频已在实机样例验证；不代表所有内容、会员及 DRM 场景通过。
- **央视影音**：客户端直达目标内容尚未实机确认。
- 进度恢复依赖站点播放器、节目/集数识别和非广告阶段；网页改版、广告、登录及 DRM 可能影响功能。没有对所有平台的全部功能完成验收。

## 隐私与数据

根据当前版本源码核对，收藏、追更进度与界面偏好通过 macOS 本地偏好存储保存；网页登录、Cookies 等由 WebKit 的持久网页数据存储管理。应用访问所选平台的官方网页，平台可按其政策处理账号、观看记录和网络请求；客户端或浏览器打开后也适用其各自政策。

安装包不包含开发者的收藏、账号、Cookies、日志或用户数据。这不构成对第三方网站不收集数据的承诺。请按各平台隐私政策决定是否登录和使用。
